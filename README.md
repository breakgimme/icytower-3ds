# Icy Tower 3DS
3DS port of an open source remake of Icy Tower 1.3.1

This project is forked from [royeldar](https://github.com/royeldar)'s remake.
## Building
To build the project, you need [devkitARM](https://devkitpro.org/wiki/devkitARM) (i personally use their [container](https://hub.docker.com/r/devkitpro/devkitarm)), [makerom](https://www.3dbrew.org/wiki/Makerom), and [bannertool](https://www.gamebrew.org/wiki)

Once you have the dependencies, just run `make`.
